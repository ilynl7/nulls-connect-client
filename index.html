Look up profile

Public. lookup_type is required (422 without it). The hidden AccountId mode accepts the full profile:{n} format.

Manual update (raw)

Mirrors the C client (main.c case 3): the backend mints a per-player game token and uses it as the bearer for POST /update — the account token alone is rejected. Both handle and image_ref are required.

Identity namespace explorer

public · read-only

The {game} path segment is a free-form namespace. laser resolves to the bound, editable profile (profile:{n}); any other segment auto-creates an anonymous identity (anonymous:{segment}:{player_id}) with a stable per-player auto handle and default avatar. 0 is the numeric alias of nullsbrawl. Anonymous handles are globally searchable via lookup_type=Handle.

Tip: use your own player id to compare your bound profile against its anonymous aliases.
